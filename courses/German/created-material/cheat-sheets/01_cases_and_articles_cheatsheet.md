# German Grammar Cheat Sheet: Cases, Articles & Prepositions

A quick-reference guide for Nominativ, Akkusativ, Dativ, and Genitiv with definite/indefinite articles and associated prepositions.

---

## 1. Definite & Indefinite Articles by Case

| Case | Question / Function | Masculine (*m*) | Feminine (*f*) | Neuter (*n*) | Plural (*pl*) |
|---|---|---|---|---|---|
| **Nominativ** | *Wer / Was?* (Subject) | **der** / ein / kein | **die** / eine / keine | **das** / ein / kein | **die** / -- / keine |
| **Akkusativ** | *Wen / Was?* (Direct Object / Movement) | **den** / einen / keinen | **die** / eine / keine | **das** / ein / kein | **die** / -- / keine |
| **Dativ** | *Wem?* (Indirect Object / Location) | **dem** / einem / keinem | **der** / einer / keiner | **dem** / einem / keinem | **den** + *(e)n* / -- / keinen + *(e)n* |
| **Genitiv** | *Wessen?* (Possession) | **des** + *(e)s* / eines | **der** / einer | **des** + *(e)s* / eines | **der** / -- / keiner |

> [!TIP]
> Notice that in **Akkusativ**, *only the masculine form changes* (`der` → `den`, `ein` → `einen`). Feminine, neuter, and plural stay identical to Nominativ.

## 2. Prepositions by Case

### Always Akkusativ (*FUDOG / DOGFU*)
* **F**ür (for)
* **U**m (around / at [time])
* **D**urch (through)
* **O**hne (without)
* **G**egen (against / towards)
* *Entlang* (along - postpositioned: *die Straße entlang*)

### Always Dativ (*aus-bei-mit-nach-seit-von-zu*)
* **Aus** (out of, from [origin])
* **Bei** (at, with, near)
* **Mit** (with, by [transport])
* **Nach** (after, to [cities/countries])
* **Seit** (since, for [duration])
* **Von** (from, of)
* **Zu** (to [places/people], at)
* *Gegenüber* (opposite)

### Two-Way Prepositions (*Wechselpräpositionen*)
> **Rule**: **Akkusativ** for movement/change of location (*Wohin?*), **Dativ** for stationary location/state (*Wo?*).

* **an** (on [vertical], at)
* **auf** (on [horizontal], upon)
* **hinter** (behind)
* **in** (in, into)
* **neben** (next to)
* **über** (over, above, about)
* **unter** (under, among)
* **vor** (in front of, before, ago)
* **zwischen** (between)

## 3. Pronoun Declensions (Subject vs Direct vs Indirect)

| Person | Nominativ (Subj) | Akkusativ (Dir Obj) | Dativ (Indir Obj) | Possessive (Nom) |
|---|---|---|---|---|
| **ich** | ich | mich | mir | mein |
| **du** | du | dich | dir | dein |
| **er** | er | ihn | ihm | sein |
| **sie** *(she)* | sie | sie | ihr | ihr |
| **es** | es | es | ihm | sein |
| **wir** | wir | uns | uns | unser |
| **ihr** | ihr | euch | euch | euer |
| **sie** *(they)* | sie | sie | ihnen | ihr |
| **Sie** *(formal)* | Sie | Sie | Ihnen | Ihr |
