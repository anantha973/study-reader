# German A1 Thematic Units — Master Index

**Your primary study material for Goethe A1 vocabulary mastery.**  
Organized by real-life theme. Every unit contains bilingual vocabulary tables, spotlights, a reading passage with English translation, and active recall drills.

---

## How to Use This Material

**Do NOT read sequentially like a book.** Use the 3-session daily workflow:

1. **Session 1 (60–75 min) — Ingest:** Read Part A (vocabulary table) out loud. For each word: read the German, the English, and say the example sentence aloud.
2. **Session 2 (60–75 min) — Read & Understand:** Read the Part C German passage. Look up nothing — just read. Then read the English translation and compare. Notice which words you missed.
3. **Session 3 (45–60 min) — Produce:** Do Part D drills. Cover the German column in Part A and test yourself. Then do the speaking prompt out loud.
