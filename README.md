# Study Reader — OVGU Magdeburg

Interactive study notes dashboard for **M.Sc. Medical Systems Engineering** at **Otto-von-Guericke-Universität Magdeburg**.

🌐 **Live Web Application**: [https://anantha973.github.io/study-reader/](https://anantha973.github.io/study-reader/)

---

### Features
* **Antigravity Modern Light / Dark Mode** with instant theme toggle
* **KaTeX LaTeX math rendering** for formulas and proofs
* **Crisp vector SVG diagrams**
* **Mobile & iPad ready** for studying anywhere

### Courses Included
- **Digital Information Processing (DIP)** (Prof. Dr. rer. nat. Andreas Wendemuth)
- **Computed Tomography I — Methods on CT** (Dr. rer. medic. Martin Volk)
- **Clinical Aspects in Imaging and Radiation Therapy**
- **Introduction to Programming Techniques in Engineering**
- **Mathematical Foundations**
- **German (Deutsch)** (A1/A2 Vocabulary, Grammar, Thematic Units & Cheat Sheets)
